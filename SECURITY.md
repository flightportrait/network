# Security

Report vulnerabilities to hello@flightportrait.com. A human reads
that address. Do not open a public issue for a report that could
harm feeders or the instance.

The map in this repository is a static client of
https://data.flightportrait.com. It does not take feeder connections
and it does not store station IPs. The ingest port and the API run
on infrastructure we operate; see docs/privacy.md for what that
side stores.
